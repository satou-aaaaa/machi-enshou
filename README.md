# 町の燃え広がり（machi-enshou）

マス目の町（木造の家・蔵・道や空き地）で、風向きと風の強さから、火元の火がどこまで燃え広がるかを当てる1日5問の学習ゲーム。正解したら、どの家を蔵に建てかえると燃える家がいちばん少ないかも選ぶ。燃えたあとの図から吹いていた風を当てる問題、川越大火と糸魚川市の火災の問題も出る。「町をつくって燃やす」で、自分で家・蔵・道と風を決めて1手ずつ広がりを見られる。

遊ぶ: <https://satou-aaaaa.github.io/machi-enshou/>

- 核：明治26年（1893年）の川越大火（1,302戸焼失）のあと、燃えにくい蔵造りの町並みが増えた（川越市「川越の歴史年表」<https://www.city.kawagoe.saitama.jp/kanko/k-about/1011706.html> ・「伝建地区の概要」）。
- 風と延焼は、消防庁「糸魚川市大規模火災を踏まえた今後の消防のあり方に関する検討会報告書」<https://www.fdma.go.jp/singi_kento/kento/items/kento209_15_houkokusyo.pdf> と内閣府「広報ぼうさい」から取りました。出典はゲームの「このゲームについて」にあります。
- マス目の広がり方は、遊びのための単純な決まりです（風なしは上下左右・弱い風は風下と横・強い風は風下の2マス先へ飛び火・蔵と道は火を止める）。本物の延焼の速さや広がり方ではありません。問題の町は練習のための例で、実在の町ではありません。
